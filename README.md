# 拾光——校园失物招领

这是 2026 年秋季软件工程课程结对编程作业项目。项目计划使用原生 HTML、CSS 和 JavaScript，制作一个适合 PC 端直接打开的响应式校园失物招领网页，并在电脑上呈现居中的手机风格界面。

## 当前进度：阶段 1（项目初始化）

本阶段已完成基础项目骨架：网页入口、奶白色与墨绿色风格的基础框架、项目标题、占位内容和底部导航栏。完整的寻物、招领、搜索、详情、发布及状态更新功能将在后续阶段实现。

## 运行方法

无需安装依赖、启动服务器或配置数据库。使用 Google Chrome 直接打开项目根目录下的 `index.html` 即可运行。

当前阶段仅验证基础页面框架；后续实现数据功能时将使用 `localStorage` 保存浏览器本地数据。`localStorage` 仅支持当前浏览器本地存储，不具备跨设备同步功能。
