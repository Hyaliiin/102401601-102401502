# 拾光——校园失物招领

这是 2026 年秋季软件工程课程结对编程作业项目。项目计划使用原生 HTML、CSS 和 JavaScript，制作一个适合 PC 端直接打开的响应式校园失物招领网页，并在电脑上呈现居中的手机风格界面。

## 当前进度

已完成项目初始化、首页与信息卡片、首页交互优化、页面高度修复、寻物/招领信息发布模块及关键词搜索。完整详情、我的发布管理和状态更新等功能仍在后续开发计划中。

## 目录结构

```text
.
├── index.html       # 网页入口
├── css/
│   └── style.css    # 页面与组件样式
├── js/
│   ├── app.js       # 页面导航、渲染与交互
│   ├── logic.js     # 表单验证、记录创建与搜索规则
│   └── storage.js   # 浏览器本地数据读写
├── tests/           # 发布和搜索的 JavaScript 自动化测试

└── README.md
```

## 运行方法

无需安装依赖、启动服务器或配置数据库。使用 Google Chrome 直接打开项目根目录下的 `index.html` 即可运行。

发布的信息和本地发布者标识保存在浏览器 `localStorage` 中；首页演示数据仍由脚本集中维护，与用户发布记录分开读取和展示。`localStorage` 仅保存当前浏览器本地数据，不具备跨设备同步功能。清理浏览器站点数据或更换浏览器后，本地发布内容不会自动迁移。
